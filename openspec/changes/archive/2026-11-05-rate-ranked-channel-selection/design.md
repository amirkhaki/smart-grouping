# Design

## Mode
exploratory

## Baseline and the single changed variable
- **Baseline**: Density-ranked channel selection (`LS8`, `LS16`, `LS32`, `LS64`, `LS128`) and cumulative slice groupings (`S0`, `C1`, `C2`, `C3`, `C4`) trained under identical probe hyperparameters (`latent_head`, `stem_channels=256`, `weight_decay=1e-3`, `label_smoothing=0.1`, `spatial_dropout=0.05`, `drop_path=0.1`, `cutmix_p=0.2`, `latent_shift=1`, `seed=42`).
- **Single changed variable**: Channel selection criterion — substituting heuristic non-zero activation density count ($\mathbb{I}(\hat{y} \ne 0)$) with empirical per-channel transmission bitrate ($r_c = \mathbb{E}[-\frac{1}{HW}\sum_{h,w} \log_2 p(y_{c,h,w})]$) computed from cached continuous latents $y$ via the frozen ELIC Gaussian conditional.

## Evaluation (protected)
- Metric: Top-1 Accuracy (%) on Caltech-256 test split (higher is better) alongside decodable bitrate in bpp (lower is better).
- Split / data version: Leak-free source-image validation split (`caltech256_elic_latents_valsplit_s0_f0.1.npz`) generated by `benchmarks.make_val_split`.
- Eval script: `benchmarks/train_probe.py` (model checkpoint selection guided by validation split, final reporting on test split).
- Oracle or best-case bound: Current best empirical result `LS128` (49.29% Top-1 at 0.1025 bpp) and full-capacity latent `C4` (48.53% Top-1 at 0.1835 bpp).

## Tiers
- Tier 1 (runs): Unit tests verifying that `compute_channel_rates_from_latents` executes on synthetic latent tensors and returns a valid $(320,)$ float array without NaNs or Infinities.
- Tier 2 (small signal, no conclusions): Verification run on 1,000 cached samples to confirm that per-channel rates produce a continuous, strictly non-tied ranking across all 320 channels.
- Tier 3 (full eval, only tier used in analysis): Full Tier-2 Kaggle execution training probes across `TR8`, `TR16`, `TR32`, `TR64`, and `TR128` (where `TR` = Top-Rate) for 30 epochs, logging results to `research/runs.jsonl`.

## Seeds and runtime
- Seeds: Probe initialization seed 42; validation split seed 0.
- Rough runtime per run: On-the-fly rate estimation on GPU: ~90 seconds; Probe training (30 epochs, parallel heads): ~12-15 minutes on 2x Tesla T4 GPUs.
- Stopping rule: If rate-ranked channels ($TR_{16..64}$) consistently underperform density-ranked channels ($LS_{16..64}$) across validation and test splits, conclude that entropy allocation in ELIC prioritizes high-frequency perceptual reconstruction rather than class semantics.

## Confounds and risks
- Contextual conditioning dependence: In ELIC, slice $k$ parameters depend on previous decoded slices $\hat{y}^{(<k)}$. The likelihood calculation must preserve the exact sequential checkerboard conditioning structure to avoid incorrect rate estimates.
- Hyperprior overhead: The hyperprior rate $R(\hat{z})$ is shared across all latents; per-channel rates isolate latent channel coding without hyperprior allocation.
