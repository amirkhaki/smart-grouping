# Design

## Mode
exploratory

## Baseline and the single changed variable
- **Baseline**: Rate-ranked channel selection (`TR8`, `TR16`, `TR32`, `TR64`, `TR128`) from `F-001` (peak 49.40% on `TR32` at 0.0475 bpp) and naive activation density (`LS8..LS128`), trained under identical probe hyperparameters (`latent_head`, `stem_channels=256`, `weight_decay=1e-3`, `label_smoothing=0.1`, `spatial_dropout=0.05`, `drop_path=0.1`, `cutmix_p=0.2`, `latent_shift=1`, `seed=42`).
- **Single changed variable**: Channel selection criterion — substituting empirical transmission rate ($r_c = \mathbb{E}[-\log_2 p(y_c)]$) with true transmitted discrete integer symbol density ($s_c = \mathbb{E}[\frac{1}{HW} \sum_{h,w} \mathbb{I}(\text{round}(y_{c,h,w} - \mu_{c,h,w}) \ne 0)]$) computed from cached continuous latents $y$ via frozen ELIC context prediction.

## Evaluation (protected)
- Metric: Top-1 Accuracy (%) on Caltech-256 test split (higher is better) alongside decodable bitrate in bpp (lower is better).
- Split / data version: Leak-free source-image validation split (`caltech256_elic_latents_valsplit_s0_f0.1.npz`) generated by `benchmarks.make_val_split`.
- Eval script: `benchmarks/train_probe.py` (model checkpoint selection guided by validation split, final reporting on test split).
- Oracle or best-case bound: `TR32` (49.40% Top-1 at 0.0475 bpp) and full-capacity latent `C4` (48.53% Top-1 at 0.1835 bpp).

## Tiers
- Tier 1 (runs): Unit tests verifying that `compute_channel_symbol_density_from_latents` executes on synthetic latent tensors and returns a valid $(320,)$ float array in $[0, 1]$ without NaNs or Infinities.
- Tier 2 (small signal, no conclusions): Verification run on 1,000 cached samples to confirm that integer symbol density produces a continuous, strictly non-tied ranking across all 320 channels, resolving the 100% density saturation artifact.
- Tier 3 (full eval, only tier used in analysis): Full Tier-2 Kaggle execution training probes across `SD8`, `SD16`, `SD32`, `SD64`, and `SD128` (where `SD` = Symbol Density) for 30 epochs with early stopping, logging results to `research/runs.jsonl`.

## Seeds and runtime
- Seeds: Probe initialization seed 42; validation split seed 0.
- Rough runtime per run: On-the-fly symbol density estimation on GPU: ~90 seconds; Probe training (30 epochs, 5 parallel heads): ~12-15 minutes on 2x Tesla T4 GPUs.
- Stopping rule: If symbol-density subsets ($SD_{16..32}$) underperform rate-ranked subsets ($TR_{16..32}$) by $>1.0\%$ Top-1 accuracy across validation and test splits, conclude that entropy allocation magnitude (bit precision) is fundamentally required over spatial activation frequency, and cease pursuing symbol density as a primary ranking metric.

## Confounds and risks
- Checkerboard autoregression: In ELIC, $\mu$ calculation alternates between anchor and non-anchor positions across the 5 slices. $q = \text{round}(y - \mu)$ must be evaluated with the exact checkerboard mask to reflect the true transmitted symbols.
- Hyperprior overhead: The hyperprior rate $R(\hat{z})$ is shared across all latents; per-channel symbol density isolates spatial latent channel activity without hyperprior allocation.
